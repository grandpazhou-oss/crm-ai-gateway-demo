# Dataverse Script Safety Inventory

All scripts require an explicit `DATAVERSE_URL`. Write-capable scripts additionally require `DATAVERSE_ENVIRONMENT_KIND=test`, a configured `DATAVERSE_PRODUCTION_HOSTNAMES` denylist, `--confirm-test-environment`, and `--confirm`. Existing phase-specific authorization gates remain in force. Publish/deploy-capable scripts also require `--confirm-publish-or-deploy`.
